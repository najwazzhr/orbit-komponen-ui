# ORBIT — Implementasi Komponen Antarmuka Web

Implementasi komponen dasar antarmuka halaman **Beranda & Katalog Keberangkatan Real-Time** dari proyek **ORBIT** (*On-demand Rides, Bookings, Items & Trips* — Platform Tebengan & Jastip Kampus Terverifikasi SSO NIM) menggunakan HTML5 semantik, CSS3 modern, dan JavaScript murni (*Vanilla JS*).

## Deskripsi Proyek
Antarmuka ini memudahkan mahasiswa mencari jadwal tebengan motor maupun layanan titip barang (*jastip*) antargedung kampus, menyaring rute keberangkatan secara langsung, menghitung estimasi biaya pemesanan, serta mengonfirmasi pembayaran QRIS melalui dialog modal yang aksesibel.

## Struktur Proyek
```text
/
├── index.html   # Struktur dokumen HTML5 semantik dan landmark halaman
├── styles.css   # Styling responsif (CSS Grid, custom properties, :has, :focus-visible)
├── script.js    # Logika interaktif (state -> render, validasi form, dialog modal)
└── README.md    # Dokumentasi proyek, struktur berkas, dan panduan menjalankan
```
